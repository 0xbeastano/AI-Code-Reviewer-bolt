# 🤖 AI Code Reviewer — Bolt Edition

An AI-powered **code review assistant** built using **Bolt for Python**.  
This project automates the process of reviewing code, identifying errors, and suggesting improvements — just like a senior engineer would.

---

## 🚀 Features

- 🧠 **AI-Powered Review Engine** — Uses LLMs to analyze and rate code quality.  
- 🧩 **Multi-Language Support** — Works with Python, JavaScript, C++, and more.  
- 🔍 **Automated Error Detection** — Catches syntax, logic, and performance issues.  
- 📊 **Scoring System** — Grades your code on readability, performance, and maintainability.  
- 📨 **Slack + Telegram Integration (Optional)** — Send AI review summaries directly to your workspace.  

---

## 🛠️ Tech Stack

- **Python 3.10+**  
- **Bolt for Python** (Slack SDK)  
- **OpenAI API / Gemini API**  
- **LangChain** (for prompt orchestration)  
- **Flask / FastAPI** (for local server execution)
